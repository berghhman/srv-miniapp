# Бот-менеджер SRV Detailing

Заявки из мини-аппа и сообщения клиентов приходят менеджеру в Telegram от бота SRV Detailing. Менеджер отвечает на сообщение клиента (свайп → «Ответить»), и бот пересылает ответ клиенту от имени SRV: текст, фото, файлы, голосовые. Под заявкой две кнопки: «Принять» (клиенту приходит уведомление) и «Закрыть».

Базы данных нет. Каждое сообщение менеджеру заканчивается строкой `#id<номер клиента>`, и по ней бот понимает, кому отвечать. По этому же тегу в Telegram находится вся переписка с клиентом.

Код тот же, что у бота GTJ. Поменялись тексты, кнопки и команды канала.

## Файлы

- `bot.js` — вся логика.
- `build-worker.js` → `dist/worker.js` — один файл для Cloudflare Workers.
- `index.js` — вход для Yandex Cloud Functions, `local.js` — для своего сервера.
- `test/bot.test.js` — проверка без интернета: `node server/test/bot.test.js`.

## Переменные окружения

| Переменная | Что это |
| --- | --- |
| `BOT_TOKEN` | Токен бота из BotFather. Хранится только в настройках воркера, в репозиторий не попадает никогда |
| `WEBHOOK_SECRET` | Любая длинная строка из букв и цифр, например `srv8Hd3kQz7Lm2Px` |
| `PUBLIC_URL` | Адрес воркера, например `https://srv-bot.aldiksema.workers.dev` |
| `MANAGER_CHAT_ID` | Номер чата менеджера или рабочей группы (бот покажет его по команде /id) |
| `MINIAPP_URL` | Необязательно. По умолчанию `https://berghhman.github.io/srv-miniapp/` |
| `ALLOW_ORIGIN` | Необязательно. По умолчанию `https://berghhman.github.io` |
| `CHANNEL_ID` | Канал для публикаций: `@srvdetailing` или число вида `-100…` |
| `APP_LINK` | Ссылка на мини-апп для кнопок в канале: `https://t.me/<ник бота>/app` (появляется после `/newapp`) |

## Запуск на Cloudflare Workers

С весны 2026 российские хостинги не достают до api.telegram.org, поэтому бот работает на Cloudflare Workers. Это бесплатно, и подойдёт тот же аккаунт, где уже живёт `gtj-bot`.

1. **Сборка.** `node server/build-worker.js` → `server/dist/worker.js`. Готовый файл уже лежит в репозитории.
2. **Воркер.** dash.cloudflare.com → Compute → Workers & Pages → Create → «Start with Hello World» → имя `srv-bot` → Deploy → Edit code. Замените весь код содержимым `dist/worker.js` → Deploy.
3. **Переменные.** Воркер → Settings → Variables and Secrets → Add:
   - `BOT_TOKEN` — тип Secret;
   - `WEBHOOK_SECRET` — тип Secret;
   - `PUBLIC_URL` — адрес воркера;
   - `MANAGER_CHAT_ID` — добавляется после шага 5.
   → Deploy.
4. **Подключение бота.** Откройте `<PUBLIC_URL>?setup=<WEBHOOK_SECRET>`. В ответе у каждого пункта должно стоять `"ok": true`. Заодно бот получит кнопку меню «Записаться», описание и команды.
5. **Чат менеджера.** С аккаунта менеджера напишите боту /id. Полученное число впишите в `MANAGER_CHAT_ID` → Deploy, затем ещё раз откройте ссылку из шага 4: у менеджера появятся свои команды. Для рабочей группы добавьте бота в группу и напишите /id там.
6. **Мини-апп.** Впишите `PUBLIC_URL` в `index.html` → `CONFIG.leadEndpoint`.

Проверка: откройте мини-апп из бота, соберите расчёт и запишитесь. Заявка должна прийти менеджеру, а клиенту — подтверждение. Потом напишите боту с другого аккаунта и ответьте на это сообщение: ответ должен прийти клиенту.

## Как работать менеджеру

- **Ответить клиенту:** свайп влево по его сообщению или заявке → написать ответ.
- **Принять:** клиенту уходит «Менеджер SRV принял вашу заявку и скоро напишет здесь».
- **Закрыть:** заявка помечается обработанной, клиенту ничего не уходит.
- **Вся переписка с клиентом:** нажмите на тег `#id…` в любом его сообщении.
- **В группе:** обычные сообщения менеджеров бот не трогает и пересылает только ответы на сообщения клиентов.

## Кнопка приложения в канале @srvdetailing

1. Канал → Администраторы → добавьте бота с правами «Публикация сообщений» и «Редактирование сообщений».
2. Перешлите боту любой пост из канала, и он ответит строкой `CHANNEL_ID: …`.
3. В BotFather: `/newapp` → этот бот → обложка `img/cover.png` → адрес `https://berghhman.github.io/srv-miniapp/` → короткое имя `app`.
4. В воркере задайте `CHANNEL_ID` и `APP_LINK = https://t.me/<ник бота>/app` → Deploy.
5. Напишите боту /app: в канале появится закреплённый пост с кнопкой «Рассчитать и записаться».

Дальше в чате с ботом:
- **/app** публикует пост с кнопкой приложения и закрепляет его. Если отправить команду ответом на своё сообщение, опубликуется оно.
- **/post** ответом на своё сообщение (текст или фото с подписью) публикует его в канале с кнопкой.
- **/post ppf** делает так, что кнопка ведёт сразу в раздел. Разделы: `ppf` (схема плёнки), `tintfit` (примерка тонировки), `quiz` (подбор), `promo` (акция), `prices`, `ceramic`, `polish`, `tint`, `clean`, `noise`, `dents`.

Метка раздела попадает в заявку строкой «Источник: …», так что видно, какой пост привёл клиента.
